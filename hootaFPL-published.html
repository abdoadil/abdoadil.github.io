Sharing Global Stories at Chandigarh University 🌍🎙️

As a Full-Stack Data Engineer and an avid Fantasy Premier League (FPL) player, I noticed a significant gap in comprehensive, user-friendly Arabic platforms offering strategic FPL analysis, which inspired me to build the "HootaFPL Super App" for the 2026/2027 season. This project was an incredible challenge in data engineering, system architecture, and UI/UX design, allowing me to transform a conceptual idea into a fully-fledged product that simplifies complex decision-making for FPL managers.

To deliver a visually stunning and highly responsive experience, I engineered the frontend using React.js, Vite, and Tailwind CSS, while robustly powering the backend with Cloudflare Workers to create a secure proxy server that intelligently bypasses FPL's strict API rate limits for an uninterrupted real-time data flow. I pushed the platform further by integrating advanced AI and LLMs to create a smart chatbot assistant that analyzes users' starting lineups and provides customized strategic reports, alongside robust features like a live market radar, an interactive transfer simulator, and an auto-syncing Fixture Difficulty Rating (FDR) dashboard.

From handling complex data pipelines to crafting an elegant user interface, this project perfectly reflects my drive to build scalable software solutions from scratch, and I invite you to explore the platform at https://abdoadil.github.io/HootaFPL/ as I am actively open to new roles and collaborative opportunities in the tech industry!
